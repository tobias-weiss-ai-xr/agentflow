# PicoLearningRooms: Learning Worlds in Unity VR

A **teaching-centric enterprise framework** built on **Unity 6000** and **PICO 4 Enterprise** VR hardware. Enables **focused learning experiences** with retrieval practice and graded exposure techniques.

---

## About

**VR Learning Experiences**: Designed for immersive educational environments that optimize engagement and knowledge retention.
- **Retrieval Practice**: Gamified recall exercises to strengthen long-term memory.
- **Graded Exposure**: Progressive challenges tailored to individual learning curves.

---

## Worlds

### Periodensystem 3D-PSE

A **Periodensystem** (Periodic Table of Elements) immersive environment featuring:
- **118 Elements**: Fully interactive 3D models.
- **5 Stations**: Thematic exploration hubs for atomic properties, materials, and reactivity.

### Mut-Training Spinnen

An exposure therapy tool for treating **arachnophobia** (fear of spiders). Uses **gradual exposure techniques** to build familiarity.

### Forschungslabore (Research Laboratories)

Based on prior **AOI research**, these spaces prioritize user engagement and procedural learning.
Ported from:
- [Periodic Table WebXR Demo](https://tobias-weiss-ai-xr.github.io/periodic-table) (Fully Open)
- [Spinnen WebXR Exposure Demo](https://pse.chemie-lernen.org) (Arachnophobia Case Studies)

## Get Started

1. Open the **Unity Editor**.
2. Navigate to **LearningWorlds** > **Open Hub Scene** to load the main menu.
3. Press **Play** in the editor to start interaction.
4. Use **WASD + Mouse** controls for navigation.

Demo projects sourced from the **original PicoLearningRooms SDK v2.50** (Git histories archived).
